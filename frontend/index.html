HELP & KNOWLEDGE BASE

Frequently Asked Questions

Everything you need to know about ImmuniLayer, GenLayer, and bounty payouts.

ImmuniLayer uses GenLayer Intelligent Contracts written in Python. When an exploit report is submitted, the contract spawns an isolated execution sandbox to verify code structure and assertion logic, then broadcasts the threat model to independent validator nodes that run LLM evaluations and reach quorum consensus under Optimistic Democracy.

Optimistic Democracy is GenLayer's consensus mechanism that enables non-deterministic operations (such as AI reasoning and live web fetching) to achieve Byzantine fault tolerance. Multiple validator nodes execute the prompt independently and use substantive equivalence comparators to agree on severity scoring.

Exploit PoC scripts are parsed and evaluated inside gl.vm.spawn_sandbox() with restricted built-in primitives. This extracts objective metrics (such as assertion counts, lines of code, and target contract interfaces) to provide ground truth that prevents AI hallucination.

Protocols deposit native GEN into on-chain escrow pools and configure maximum reward caps for CRITICAL, HIGH, MEDIUM, and LOW tiers. When a vulnerability is verified by consensus, the contract transfers the tiered bounty in native GEN directly to the researcher's wallet. If a report is rejected, no value leaves escrow.

ImmuniLayer implements an on-chain appeal path via appeal_report(). Any party can record a substantive appeal justification, which is stored permanently on-chain.

ImmuniLayer supports PoCs and target smart contracts written in Solidity (Foundry/Hardhat), Python (py-genlayer), Vyper, Rust, and standard EVM bytecode.

Project owners connect their wallet and click "+ Create Bounty Escrow". You specify your repository URL, scope, initial escrow deposit, and payout caps. The contract locks the deposited GEN and instantiates an active on-chain vault.
